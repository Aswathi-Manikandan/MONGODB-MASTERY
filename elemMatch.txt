### `$elemMatch` in MongoDB

`$elemMatch` is used when you want to find **an array element that satisfies multiple conditions at the same time**.

Your `orders` collection has an `items` array:

```js
items: [
    {
        productName: "iPhone 15",
        quantity: 1,
        price: 69999
    },
    {
        productName: "AirPods Pro 2",
        quantity: 1,
        price: 24999
    }
]
```

### Basic syntax

```js
db.orders.find({
    items: {
        $elemMatch: {
            condition1,
            condition2
        }
    }
})
```

### Example from your dataset

**Find orders where one item has:**

* `quantity` greater than `1`
* AND `price` greater than `25000`

```js
db.orders.find({
    items: {
        $elemMatch: {
            quantity: { $gt: 1 },
            price: { $gt: 25000 }
        }
    }
})
```

Here, MongoDB looks for **one single item** that satisfies both conditions.

---

### Why do we need `$elemMatch`?

Suppose an order has:

```js
items: [
    {
        productName: "Product A",
        quantity: 2,
        price: 10000
    },
    {
        productName: "Product B",
        quantity: 1,
        price: 50000
    }
]
```

If you write:

```js
db.orders.find({
    "items.quantity": { $gt: 1 },
    "items.price": { $gt: 25000 }
})
```

MongoDB can satisfy these conditions using **different array elements**:

```text
Product A → quantity > 1 ✅
Product B → price > 25000 ✅
```

But maybe you wanted **the same product** to satisfy both conditions.

That's where `$elemMatch` comes in:

```js
db.orders.find({
    items: {
        $elemMatch: {
            quantity: { $gt: 1 },
            price: { $gt: 25000 }
        }
    }
})
```

Now MongoDB requires:

```text
ONE item
 ├── quantity > 1 ✅
 └── price > 25000 ✅
```

### 🧠 Remember

```text
$in
→ One field → multiple possible values

$or
→ Multiple alternative conditions

$elemMatch
→ One array element → multiple conditions
```

For your `orders` collection, `$elemMatch` is mainly useful with the **`items` array**.
